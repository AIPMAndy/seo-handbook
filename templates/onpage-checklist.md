# 发布前逐页验收（15 项）

- [ ] 本页解决一个真实、清晰的用户意图；不是为了凑页面数量。
- [ ] 有自己可以证明的独特信息 / 实测 / 工具 / 案例。
- [ ] URL 简洁稳定，HTTPS 可打开。
- [ ] HTTP 返回 200，匿名能访问。
- [ ] 源 HTML 可找到 H1 和重要正文；不是空壳 JS。
- [ ] Title 准确且不同于网站其他重要页面。
- [ ] Description 与可见内容一致。
- [ ] 有语义清晰的 H1 / H2，手机可读。
- [ ] Canonical 自指或指向明确相关规范页。
- [ ] 无误加 noindex；robots 不误阻挡。
- [ ] 从导航或上下文内链能到达。
- [ ] 图片有适当 alt / 尺寸，外链可访问。
- [ ] Schema 与真实页面一致（确有适用类型时）。
- [ ] CTA 能从前端到后台完成，实际测试过。
- [ ] 留下版本、负责人、下一次数据检查日期。
