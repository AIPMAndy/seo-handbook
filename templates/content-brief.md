# SEO 内容 Brief｜可直接复制

## 1 读者和任务
- 目标用户、场景、触发搜索的原因：
- 一句话说明读者看完可以完成什么：
- 主查询、关联查询（带来源与核查日期）：
- 搜索意图（了解 / 做到 / 比较 / 购买）：
- 当前搜索结果常见页面类型：
- 预定页面类型与 URL：

## 2 独特证据
- 一手经验 / 实测截图 / 业务案例：
- 官方政策 / 功能链接：
- 与现有结果相比新增的价值：
- 不能验证的结论（删掉或标示假设）：

## 3 页面骨架
- Title（准确、简洁、和正文一致）：
- H1（回答真实问题）：
- Description（真实说明能获得什么）：
- 第一屏直接回答：
- H2：适用对象与使用前提
- H2：准备材料 / 前置条件
- H2：Step 1 / Step 2 / Step 3（每步要有验收）
- H2：失败处理 / 常见问题
- H2：下一步行动
- 必须出现的示例 / 截图 / 视频：
- 指向本页的内链来源：
- 本页链接出去的支持内容：
- CTA（一个主要动作及跳转地址）：

## 4 发布验收
- [ ] URL HTTPS 200，匿名可打开
- [ ] 源 HTML 包含正文与唯一 H1
- [ ] Title / description 不与主站其他页重复
- [ ] Canonical 指向正确 URL
- [ ] 网站导航与正文有真实 href
- [ ] 事实与证据相符，案例已获公开许可或标注模拟
- [ ] 手机可阅读、能完成 CTA
- [ ] GSC 后续检查与变更日志已安排
