# SEO 转化事件定义表

| 事件 | 业务含义 | 触发条件 | 去重规则 | 验证方式 | 数据负责人 |
|---|---|---|---|---|---|
| visit_service | 访问服务页 | 页面访问（需确认渠道归因） | 按会话 | 分析系统调试 | |
| form_success | 提交有效表单 | **后端保存成功** | 同一 submission_id 只算一次 | 3 次成功+1 次失败测试 | |
| qualified_lead | 合格咨询 | 人工/CRM 按统一标准确认 | 同人同需求去重 | CRM 对账 | |
| paid_order | 成交订单 | 订单实际支付成功 | 订单 ID | 财务/订单后台 | |

注意：GSC 点击数不等于 GA4 会话数，更不等于有效咨询。不要用按钮点击替代提交成功。
