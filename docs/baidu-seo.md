# 补充实战：百度 SEO 从 0 提交与复盘（2026-11-05 核对）

适合主要目标客户通过中国大陆百度网页搜索寻找服务的站点。核心逻辑仍是用户需求、可抓取内容、优质页面、搜索数据和实际业务转化，但**Google Search Console 与百度搜索资源平台是不同系统**，提交方式和配额不能混用。

## 1. 拿到站点管理权限

**操作**：打开 https://ziyuan.baidu.com/site/index ，登录百度搜索资源平台，添加你能合法管理的真实网站，按平台当前提示执行验证。优先核对站点与最终公开网址是否一致。

**验收**：站点管理页显示可操作的站点，不只是网页前台能打开。

**卡住怎么办**：没有域名控制权就向网站所有者申请；不要通过冒名验证获得权限。平台历史文章说明了文件/HTML 标签等验证方式，但以当前控制台实际可用选项为准。

## 2. 准备提交的 URL

**操作**：按章节 17–21 检查 URL 状态码、内容、内链、规范版本与可访问性。整理 HTTPS 200 的正式页面清单。排除登录页面、无内容测试页、不可访问页和明显重复页。

**验收**：`templates/technical-audit.csv` 中每个 URL 都能匿名打开且页面完整。

**卡住怎么办**：如果服务器不在大陆、访问速度存在波动，先在目标用户所在地手动验证真实可用性，不以搜索引擎收录数据替代网络可达性检查。

## 3. 普通收录工具提交

**操作**：打开 https://ziyuan.baidu.com/linksubmit ，进入已验证站点，按当前开放的 API、手动或 sitemap 提交入口提交真实页面。此前官方说明存在配额、提交格式限制；以账号当前提示为准。

**验收**：保留提交方式、URL、日期与平台反馈。**提交成功只意味着提交环节完成，不是收录成功**。

**卡住怎么办**：报错时先检查站点验证、URL 所属站点、提交配额、内容是否重复。官方明确说链接提交可缩短发现时间，无法解决内容是否被收录。

## 4. 看索引与流量数据

**操作**：在百度搜索资源平台的站点资源中查看“索引量”“流量与关键词”“抓取异常”“抓取诊断”，按日期、页面和查询核对真实变化。

**验收**：建立百度数据周报，字段包括“索引、展示/访问（按平台实际可得口径）、业务有效咨询”，不要机械照搬 GSC 字段。

**卡住怎么办**：报表尚无数据时先记录“无数据”并检查内容是否可访问，而不是填上预估流量。

## 5. 用商业结果做取舍

**操作**：检查从百度自然搜索来的实际访问、表单提交、电话和订单。只有满足真实业务需求且合格咨询增加，才考虑增加同主题内容投入。

**验收**：每月列出“保留 3 个主题 / 改进 3 个页面 / 停止 1 个无关方向”。

**卡住怎么办**：如果流量增加但咨询不增加，回到用户意图、页面可用性与服务定位，而不是持续批量生产文章。
