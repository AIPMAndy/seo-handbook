# 排障树｜用户说“SEO 没效果”时先问什么

## A. 页面根本打不开

**问题**：页面公开访问是 404/403/500、DNS 错误、证书错误。

**行动**：无痕打开精确 URL；用 `curl -IL https://...` 检查；对照发布日志和 CDN/WAF；检查域名是否指向正确服务。**验收**：匿名用户能在目标地区 HTTPS 200 获取正文。**卡点**：HEAD 返回异常时换 GET，不要直接推断整个页面坏了。

## B. 页面可访问但 Search Console 显示未索引

**先分类型**：“未发现”“已发现 - 未抓取”“已抓取 - 未收录”“重复 - Google 选择其他规范页”“被 noindex 排除”。不同原因不能统一“提交 sitemap”解决。

**行动**：查 sitemap/内链、HTTP、robots、noindex、canonical、内容是否独特；用 GSC URL 检查和页面索引报告交叉核对。

**验收**：把具体状态、页面 URL 和修复动作写入 `templates/technical-audit.csv`。**注意**：即使条件满足也不保证索引。

## C. 已索引但没有展示

**行动**：首先检查实际用户是否搜索该需求，Google 查询是否能找到相关结果；看是否选错市场语言或意图、页面是否有独特信息与内链。**验收**：给出关键词证据和一张意图匹配表。

## D. 有展示但没有点击

**行动**：GSC 只筛一个 URL + 一组同意图查询；检查排名位置、标题、摘要与 SERP 页面类型。必要时补上比较/步骤/价格因素。**验收**：一处明确修改和发布日志，留给后续观察。**卡点**：CTR 受展示位置与搜索结果样式影响，不存在统一应该达到的固定值。

## E. 有点击但没有咨询

**行动**：检查关键词购买意图、页面针对客户的价值、可公开证据、CTA 是否可点、表单提交是否真的成功。**验收**：至少完成 1 次真实提交测试、1 份业务漏斗表。

## F. 有咨询但无法成交

**行动**：反查咨询是否有效、能否交付、报价是否透明、案例是否足够、响应速度是否合理。**验收**：统一“合格线索”定义，按实际商机复盘。**卡点**：问题可能在产品和销售，而非 SEO。

## G. 网站刚迁移，流量突然下降

**行动**：先核查 URL 映射、重定向、noindex、canonical、robots、GSC 告警、日志和分析工具是否丢数据。**验收**：高流量旧 URL 每个有去向且没有循环或错误跳转。

## 30 分钟排障次序

- 0–5 分钟：是否是实际访问问题还是数据上报问题。
- 5–10 分钟：HTTP、robots、noindex、canonical、重定向。
- 10–15 分钟：Search Console 索引/安全/手动操作消息。
- 15–20 分钟：按目录、国家、设备、品牌/非品牌分解变化范围。
- 20–30 分钟：提出优先修复动作、负责人和复测日期。

## 自检工具（无需付费 SaaS）

```bash
# 检查你有权限诊断的一个公开网页的 title、H1、canonical、noindex 等：
python3 scripts/check_url.py https://example.com/

# 检查本开源项目自身的 62 个 HTML 页面、内链和元数据：
python3 scripts/site_audit.py _site

# GSC 导出 CSV 后，只按可观察的展示/CTR 做待核查排序（不猜搜索量）：
python3 scripts/gsc_opportunities.py templates/gsc-sample.csv --top 10
```

GSC 工具只是一个排序器，不能判断用户真正的购买意图；你还需要手动做关键词/页面层面的业务筛选。
