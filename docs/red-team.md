# 对抗式审核｜SEO Handbook V1 → V2

**审核对象**：教程的数据结构、静态网站、2026 版官方 SEO 说明、30 天计划、前端工具、生成与自动部署链路。每个问题必须说明证据 → 严重程度 → 修复 → 复测。

## 五个攻击者角色

1. **零基础小白**：不懂 GSC、sitemap 或 canonical，点哪里？输入什么？完成怎么判断？
2. **搜索质量审查者**：是否批量 AI 拼接、虚假排名承诺、买外链、乱加 schema？
3. **SEO 工程师**：是否能让抓取系统读到独立网页？metadata/canonical/sitemap 是否一致？
4. **付费企业客户**：带来的是对的客户、有效咨询和订单，还是只有流量？
5. **前端与开源维护者**：JS 关闭会怎样？手机能用吗？CI 能查出坏链接吗？仓库能复现吗？

## 第二轮：故障注入检查（必须自动化）

- 删除被内部链接引用的目标页 → 检查器应报告 broken internal href。
- 故意写入双 H1 → 检查器应报告 H1 数量错误。
- 改坏 canonical URL → 检查器应报告 mismatch。
- 改坏 JSON-LD → 检查器应报告无法解析。
- 把 HTML 加入 `noindex` → 检查器应报告 accidental noindex。
- 在 sitemap 添加不存在的 URL → 检查器应报告集合不一致。

对应 `tests/test_site.py` 的临时目录故障注入测试；无需联网。

**课程完备 ≠ 搜索结果排名。** 本项目允许宣称“可部署、可跟做、具备自动审核脚本”，但“实际网站收录、长期获客效果、适配所有 CMS”只能在真实用户站点上线后按证据确认。

## V2：第二轮对抗式审核（2026-11-05）

### 新增审查角色

- **初学者**：不知道自己属于新站、老站、转化站。现在可用 5 问诊断与 6 条 7 天路线。仍需外部新手跟做。
- **数据分析师**：GSC 表中高展示/低 CTR 的“观察分值”不是丢失点击量；两期数据 CSV 对比不证明 SEO 因果。脚本会拒绝不同维度的表和重复标签。
- **AI 搜索研究员**：原版只讲人工抽样，忽略 2026 Google GSC 生成式 AI 报表及 Bing AI Performance。已新增真实官方测量路径，区分 impressions/citations/visits/leads。
- **安全审查员**：CSV 文件内容可能以公式开头，导出到 Excel 有公式注入风险。浏览器和 CLI 输出已对危险前缀中和；浏览器端所有用户提供的标签采用 DOM textContent。
- **产品质量负责人**：课程长度不能代表价值。13 个 SOP 各有应用前提、操作证据与失败回退；新增 10 项人工审核门槛。
